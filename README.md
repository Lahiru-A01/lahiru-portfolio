## 🛠 Why I Built This
Most portfolios are static and simple. I wanted to build something that reflected the **Next.js 15** ecosystem while maintaining a formal, academic aesthetic that matches my work at DTU. 

The goal was to create a high-performance hub that bridges the gap between my **AI/Computer Vision** research and my **Frontend Engineering** skills. Whether it’s geometric alignment in face recognition or crafting a Gen Z fashion brand, this site is where those worlds meet.

## 🧬 Technical Deep Dive

### The Frontend Stack
* **Next.js 15 & Turbopack:** I opted for the latest App Router architecture. Using Turbopack during development allowed for near-instant hot-reloading, which was crucial for fine-tuning the UI.
* **Tailwind CSS v4:** The site uses a custom-engineered "Formal Slate" theme. It’s fully responsive and respects system-level dark mode preferences.
* **Zero-Dependency Icons:** To keep the bundle size small and the load times fast, I implemented custom SVG components for social links rather than pulling in heavy external libraries.

### Featured Research & Projects
* **Expression-Invariant Face Recognition System:** A modular pipeline utilizing **BlazeFace** for detection and **Affine Transformations** for geometric alignment. This project focuses on identity matching even when facial expressions change—a significant challenge in modern vision tasks.
* **ZYLA Branding:** A full-stack e-commerce exploration focusing on Western street aesthetics. [View the ZYLA live demo here](https://ecommerce-app-eight-rouge.vercel.app/).

## 🚀 Running it Locally
If you'd like to poke around the code or run it on your machine:

1.  **Clone the repo:**
    ```bash
    git clone [https://github.com/Lahiru-A01/lahiru-portfolio.git](https://github.com/Lahiru-A01/lahiru-portfolio.git)
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Spin up the dev server:**
    ```bash
    npm run dev
    ```
    The site will be live at `http://localhost:3000`.
